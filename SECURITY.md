# Security

Spatial PC is an early development project and is not ready for unattended or Internet-exposed use. The current lab host requires TLS 1.3 and an explicitly paired client certificate. Normal user pairing and production hardening remain unfinished.

Do not post credentials or private desktop content in issues. Report security vulnerabilities through this repository's private vulnerability reporting feature when available. Otherwise, contact the maintainer through https://peterwang.tech/contact without including secrets in the initial message.
