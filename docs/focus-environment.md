# Focus environment

Windowed mode stays in the shared space so it can coexist with Mac Virtual Display. Focus uses a progressive ImmersiveSpace with a quiet studio backdrop: one 1024×512 gradient texture, an inward-facing dome, and an unlit floor. There are no per-frame environment animations or dynamic lights. The same native desktop window stays visible above the environment, retaining its position, resize handle, and hover controls. Returning to windowed mode dismisses only the environment while retaining the stream. Focus does not copy video into a second RealityKit display surface.

Progressive immersion lets the system's Digital Crown control how much of the custom environment surrounds the person. The range is explicitly 0...1, initially 0.5. At zero the background disappears while the desktop window stays visible; full immersion covers passthrough. System safety and interaction overlays remain controlled by visionOS.

The simulator displayed the backdrop with a changing synthetic TLS stream and returned to the window without reconnecting. Signed device Lab builds pass. Physical build 2 confirmed correct colors, gaze-revealed controls, and window return. It exposed the system-default minimum; build 3 allowed the full Crown range but also clipped the former RealityKit desktop at zero. Build 4 keeps the native desktop outside the progressive portal and is undergoing the targeted physical retest. Comfort and prolonged use remain to be evaluated. This is a minimal environment, not a finished library of selectable rooms.

References: [Apple window visibility in immersive spaces](https://developer.apple.com/documentation/swiftui/immersivespace), [custom Crown range](https://developer.apple.com/documentation/swiftui/immersionstyle/progressive(_:initialamount:)), [Apple progressive immersion](https://developer.apple.com/documentation/swiftui/immersionstyle/progressive), [building an immersive environment](https://developer.apple.com/documentation/realitykit/construct-an-immersive-environment-for-visionos), and [unlit material tone mapping](https://developer.apple.com/documentation/realitykit/unlitmaterial/init(applypostprocesstonemap:)).
